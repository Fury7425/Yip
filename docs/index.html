§1

What it does

Records what the microphone hears, saves it where you can find it, and gets out of the way.

  1. One-key recording

    Ctrl+Alt+R

    Starts and stops a take from any app, even with the window closed. Rebind it in Settings.

  2. The recording pill

    Top or bottom

    A small capsule shows the recording light, elapsed time and a live meter. Tap it for Pause and Stop. It can shrink to a single dot and let clicks pass through.

  3. Pause without gaps

    Instant resume

    The device stream stays open while a take is held, so resuming is immediate and the clock doesn’t count the pause.

  4. A meter you can trust

    Log · peak hold

    Logarithmic scale, peak hold, a clip lamp, and counters for overruns and dropped frames — if anything went missing, you’ll know.

  5. Built-in playback

    Ctrl+P

    Click a recording and it plays. Scrubbing is smooth because the capture engine simply runs in reverse.

  6. Lives in the tray

    One instance

    Closing the window keeps Yip running and hands its memory back. The hotkey keeps working; the tray icon brings the window back where you left it.

  7. Feels like Windows

    Mica · light/dark

    WinUI 3 with Mica and acrylic, following your theme, with keyboard shortcuts throughout.

§2

What it won’t do

  • AI
  • Cloud
  • Telemetry
  • Accounts

Yip makes no network calls. Not for analytics, not for updates, not once.

Your recordings are plain files in Music\Yip. Open them with anything.

This page is the same: no trackers, no cookies. It fetches its fonts and nothing else, and the demo up top never asks for your microphone.

Formats

Every encoder ships with Windows, so Yip bundles none of its own.

MP3128 – 320 kbpsSending to anyone, playing anywhere.

§4

Inside

Native parts only. No web view, no runtime to install, no garbage collector anywhere near the audio.

UI

WinUI 3

C++/WinRT, self-contained.

Boundary

C ABI

A plain C header. Nothing else crosses.

Engine

Rust

Capture thread never allocates, locks, blocks or logs.

Device

WASAPI

Event-driven, Pro Audio priority.

0%CPU while idle. Nothing ticks until a take starts.
20HzMeter refresh on the pill — enough to read, not enough to keep the GPU awake.
0Locks between the microphone and the file. A lock-free ring carries every sample.

Get it

  1. Download yip-setup-x64 from the latest build.

  2. Run it. It installs for you alone, so there’s no admin prompt.

  3. If SmartScreen objects, that’s because the build is unsigned and new.

    Why, and what to do.

  4. Press Ctrl Alt R.
